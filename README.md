# ASYLUM COMMUNITY — Jersey Drop

Standalone jersey showcase website for the Asylum Community V1–V4 collection.

## Features
- Responsive jersey collection page
- V1–V4 jersey previews
- Click a jersey to open a larger image preview
- Order CTA links to the Google Form

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Deploy with Vercel using the `main` branch, build command `npm run build`, and output directory `dist`.
